## 三、B7 根因闭环（Redis 连接被关闭）

**现象**：主机经 `127.0.0.1:6379` 用 redis-py 连接被 `ConnectionReset(10054)`；容器内 `redis-cli ping` 正常。
**根因**：`configs/redis.conf` 中 `bind 127.0.0.1` + `protected-mode yes`。容器内 Redis 仅监听 loopback，Docker 端口映射自宿主来的连接走容器 eth0（非 127.0.0.1），故 TCP 握手成功后 Redis 立即关闭 —— 即 Phase 0 登记的 **B7** 真实根因。`protected-mode` 改 no 无效（`bind` 才是拦截点，且为**启动期**参数，`CONFIG SET` 无法运行时改）。

**处置（ISS-015 形态 B + client 带密）**：
1. `configs/redis.conf`：`bind 0.0.0.0` + `protected-mode no` + 新增 `requirepass auscult-dev-redis`；
2. 重建 `auscult-redis` 容器（bind/requirepass 为启动期参数，须 recreate）；
3. `alarm_engine.py` Redis 连接带密；本地实验可 `--allow-no-redis` 降级为 in-process 去重（生产必须真 Redis）。

**验证**：无密连接被拒、带密 PONG；引擎经真实 Redis 完成去重。
