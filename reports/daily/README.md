# reports/daily/ 日报规范

> 用途：记录 Phase 0（D0–D10）每一天的**实际发生了什么**，作为 `reports/p0-gate-review.md` 与风险登记的原始素材。

---

## 一、命名规范

```
reports/daily/D<n>-status.md      # n = 1..10，对应计划中的 D1–D10
reports/daily/D0-status.md        # 如需记录决策冻结日，用 D0
```

- 一天一份，**不合并、不覆盖**；当日写完后不再改写结论，修正走文末"修订记录"。
- 文件名固定为 `D<n>-status.md`，便于索引与排序。

## 二、每份日报必须包含的五节

| 节 | 内容 | 要求 |
|---|---|---|
| 1. 当日目标 | 引用计划中对应日期的目标与出口里程碑 | 必须原文引用里程碑编号（如 M0.1） |
| 2. 逐任务执行表 | 任务编号 / 计划动作 / **实际状态**（已完成 / 部分完成 / 未开始 / 阻塞）/ 产出物 / 证据 | 状态必须写实，"部分完成"必须写清缺哪一半 |
| 3. 实测事实与证据 | 命令、原始输出摘要、文件路径、digest、时间戳 | **只写真实跑过的东西**，未跑的不写 |
| 4. 发现的问题与风险 | 编号 / 描述 / 影响 / 处置 / 是否新增风险项（对应 R1–R16） | 新增风险须给出临时编号并建议纳入 `docs/prj-ledger-risk-register.md` |
| 5. 次日待办与阻塞 | 待办清单 + 阻塞项 + 解除阻塞需要谁做什么 | 阻塞项必须写明"卡住的是哪个下游结论" |

可选附加节：`时间开销`（计划 vs 实际）。

## 三、填写纪律

1. **状态四态制**：`已完成` / `部分完成` / `未开始` / `阻塞`。禁止使用"基本完成""差不多"这类模糊表述。
2. **区分"设计就绪"与"实测完成"**：
   - 产出物是文档/配置方案 → 记 `已完成（设计就绪）`，并说明**动作是否已执行**；
   - 产出物是实测数据 → 记 `已完成（实测）`，必须附原始数据路径。
3. **未闭环项必须点名**：任何未达到 DoD 的条目，必须在第 5 节出现，且写明触发条件（例：T1.9 未通过 → 立即启动降级评估）。
4. **不编造**：没有跑过的实验不写进"实测事实与证据"。
5. **引用基线**：环境相关数据统一引用 `env/env-baseline-v2.md` 的版本号，不另起一套描述。

## 四、日报与里程碑的关系

| 日报 | 对应出口 | 该日报的 DoD 校验必须覆盖 |
|---|---|---|
| `D1-status.md` | **M0.1** | 环境基线 / Schema v1 冻结 / 数据来源清单含兜底 / 实验登记模板可用 / TDengine 授权结论已出 |
| `D2-status.md`、`D3-status.md` | **M0.2** | V1 八项指标齐全（首次与重试分开 + 云端 baseline）/ 分工决策含 70–90% 中间区间 / 50 条评测集 + 标注规范 |
| `D4-status.md`、`D5-status.md` | **M0.3** | Milvus digest + jieba analyzer 抽检通过 / 参数基线表 + 检索对比 / Schema 映射（4 类边界）+ `query_sensor` 契约 + 告警路线 |
| `D6-status.md`、`D7-status.md` | **M0.4** | checkpoint 恢复/幂等/并发/体积全部有结论 / Redis 模板 + 审核生命周期策略 |
| `D8-status.md`、`D9-status.md` | **M0.5** | 资源实测表 + 分组策略 + 替代代价 / 版本锁定清单 + 风险册 + MVP 停止条件 |
| `D10-status.md` | **M0.6** | 六项验证逐项 Pass/中间/No-Go / 中间项处置动作 + 指标代价 / 版本锁定与报告 digest 一致 / P1 移交清单可直接使用 |

## 五、每日通用规则（开工前必查，与计划 §八 一致）

- [ ] 今日 V 项的 **Pass / 中间 / No-Go 已定义**
- [ ] 实验按 `docs/prj-template-experiment-log.md` 登记（digest / seed / prompt 版本 / commit）
- [ ] 原始数据落盘 `experiments/**/raw/`（可追溯，含断点续跑）
- [ ] 结论引用 `env/env-baseline-v2.md` 版本号

> 以上四条不满足，**当日不开工**。
