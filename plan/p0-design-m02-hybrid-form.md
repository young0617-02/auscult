## 一、架构目标（分工位移，非全上云）

**核心翻转**：本地从“工具调用主力”退为「私有数据侧 + 安全兜底 + 检索底座」；生成式工具调用（R-2 规划 + R-3 参数抽取）交云端。

| 角色 | 归属 | 原因 |
|---|---|---|
| **R-1 意图识别** | 本地 7B | 分类任务、轻量、延迟敏感 |
| **R-2 工具调用规划** | **云端** | 结构化输出纪律要求最高，本地 7B 最薄弱 |
| **R-3 参数抽取** | **云端** | 参数值正确率（本地 0.27–0.43）不达标 |
| **R-4 证据归纳/诊断推理** | 本地（**合规锁死**） | 涉证据原文，不外传；EXP-R4-001 已 Pass（ISS-014 闭环） |
| **R-5 审核摘要生成** | 本地 | 涉私有报告内容，轻任务 |
| 检索层（Milvus/Neo4j/TDengine/PG/BGE-M3） | 本地 | V2 已 Pass |
| 写操作/审计（generate_report 图外执行 + PG 权威 + 追加审计） | 本地 | V3/V5 已闭环 |
| **有效拒绝边界** | 本地 | qwen 100% Pass |
| **降级/离线兜底** | 本地 | Must #12，断网即死不可接受 |

**一句话**：工具调用上云，证据与安全兜底留本地。

## 二、多工具编排：方案 A「云端单响应编排」（主）——方案 B 已实测否决

> **裁决变更（2026-09-30，P6 实测）**：原「方案 B 拆单工具多次调用」经 **EXP-V1-009（拆步）vs EXP-V1-010（修复 ISS-024 后单响应基准）** 干净 A/B 实测为**负结果**——多工具档 qwen **40%→20%**、deepseek **13.3%→0%**；机制为 qwen 拆步后步序/工具名 15/15 全对但失败全部收窄到参数值错（瓶颈转移而非消除），deepseek 步骤 2 重复调用步骤 1 工具 + think 打满 `max_tokens` 致格式退化。故 **B 不再采纳**，多工具改由**云端单响应编排（方案 A）**承担。

| 项 | 内容 |
|---|---|
| 手段 | 多工具目标由**云端 R-2 在单响应内一次性给出多个 `tool_calls`（不拆步）**；云端 27B 的单响应编排能力显著强于本地 7B（EXP-V1-005 云端多工具 50% vs 本地双模型 0.00–0.20） |
| 依据 | 方案 A 即"生成式 R-2/R-3 上云"在多工具分支上的直接延伸；拆步（B）已由 P6 证否（见上） |
| 判据口径 | 多工具档**主判据 = 用例级首次通过率**（`docs/p0-spec-gate-criteria.md` §3.1.1），**不再使用步骤链口径**；档线仍 ≥70%（不因改方案放宽） |
| 代价 | 单响应多工具 = **一次往返**（延迟低于拆步）；但云端多工具历史实测仅 50%，若未达 70% 须**如实记录未达标**并另议 |
| 留痕 | 记录多工具用例的单响应成功/失败明细 + 云端调用次数 |

## 四、端到端控制流（本地编排 → 云端工具调用）

```
用户输入/告警
   ↓
[R-1 意图识别]（本地）→ 判定类型
   ↓
调用链（每步 = R-2 云端选1工具 → R-3 云端抽参）→ Schema v2 校验 → 本地执行工具
   ↓  （多工具：云端单响应一次性编排多个 tool_calls，**不拆步**，一次往返）
证据收集完成
   ↓
[R-4 证据归纳/诊断推理]（本地，读证据→写根因+结论+evidence_refs）
   ↓
[R-5 审核摘要]（本地）→ 上报（写操作/审计本地，PG 唯一权威）
```

## 八、实测结论（EXP-M02-001，2026-09-30）

| 项 | 实测 |
|---|---|
| 首次成功率 | **0.60（12/20）** |
| 分档 | 单工具 67% No-Go ｜ 参数校验 75% 中间 ｜ 多轮 33% No-Go ｜ 无效拒绝 67% No-Go ｜ **多工具 50% 中间** |
| 整体 | **No-Go**（最差档 = 单工具/多轮/无效拒绝） |
| vs §六 预期（≥95%） | **未达**（0.60 ≪ 0.95） |
| 多工具集合覆盖 | **1.00（4/4）** → 编排无问题，卡参数值 |
| 参数值正确率 | 0.5882（与 EXP-V1-005 云端口径 0.5294 同源） |
| 云端调用/延迟 | 20 次（未超预算锁）；热 P95 22529 ms |

> **指向**：M0.2 处置链 ①②③④ 已全部执行仍 No-Go；云端 27B 亦仅 0.60，提示**判据/用例参数值口径**是共同瓶颈。下一步应优先**复审参数值判据与用例口径**，而非继续换/加模型。详见 `experiments/v1/EXP-M02-001.md`。
