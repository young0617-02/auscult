## 〇、复审范围与原则

- 复审对象：`evals/v1_cases.jsonl`（20 条）+ `schemas/tools_v1.json`（5 工具 / 冻结 v1）。
- 依据：`EXP-V1-003` 约束解码全量实测失败归类（`reports/v1-report.md` §4.4：剩余失败集中于「参数值错」，多工具双模型 0.00）、参数归一化 `EXP-V1-NORM`（uplift=0，瓶颈在参数语义选择 + 多工具编排）、云端上界 0.60（EXP-V1-002）/ 0.55（EXP-V1-005）。
- **三条不越界**：
  1. 只修「判据过严 / 口径歧义 / Schema 与用例不一致 / 枚举过苛」，**不放宽对"模型组织能力"的要求**；

## 三、Schema v2 简化建议清单（按优先级）

> 每一项须在 v2 冻结时同步 `version-lock.md` §二（schema）并升版判分器 `judge_tools.py` 对应 `TIER_CRITERIA`。

### 1. 多工具 → 拆「单工具多次调用」判定（高，对应架构切分 §4.6 方案 B）
- 不改 Schema 本体，但**新增约定**：v2 允许多工具目标拆成**按序的单工具调用链**，每步只选 1 个工具。
- 用例 v1-007/008/009/010 改判：不要求单响应多工具，而要求「两步均出现且参数各自完整」；漏一步记一步失败（分步可定位到具体工具）。
- **判据**：仍属「多工具」档（≥70%），但判定对象从「单响应完整」放宽为「步骤链完整」，可达成性显著提升。

### 2. `window` / 时间单位变体语义等价（高）
- v2 将时间单位变体纳入 `time_range_equivalence`（与现有 ±10% 同轨）：`15m` 与 `15min`/`900s/60` 等价、`1h` 与 `1hour`/`3600s/3600` 等价；仅当不同量纲时判错。
- 判分器：`window` 校验由等值比对 → 量纲归一后比对。

### 3. `aggregation` 超限类语义收敛（中）
- v2 为 `count_over_limit` 增加已归一别名表（`count`/`over_limit`/`exceed_count` 视为等价，服务端统一为 `count_over_limit`），提交层做 canonical 归一（复用 `scripts/param_normalizer.py` 的 R-3 中性变换经验）。
- **注意**（沿用 EXP-V1-NORM 教训）：归一化必须是**对比较器的中性变换**，不得改变非超限聚合语义。

### 4. `time_range` 绝对时间时区等价（中）
- v2 规定 ISO8601 绝对时间的判定为「**时区等价**」：同一瞬间的 `+08:00` / `Z`(UTC) 视为等价，仅当时刻不同才判「参数值错」。
- 判分器：绝对时间先归一到 UTC 再比对。

### 5. `generate_report` 考点拆开 + 写操作边界厘清（中）
- v2 将写操作判定收敛为**两档**：
  - **意图**：是否产生 `generate_report` 调用（role-decision §4.6：写操作/审计留本地）；
  - **必填**：`device_id` / `diagnosis_summary`(非空) / `evidence_refs`(≥1 条，type 枚举) —— 判分器仅此三项；
  - `idempotency_key` / `severity` / `format` / `recommended_actions` 降为**非必填宽松**（不参与正确性判定，仅校验存在性/正则合法性）。
- 理由：`idempotency_key` 为运行时 V5 幂等机制，模型自生成值**无法也不应**作为抽取质量判据。

### 6. 无效拒绝（无改，保持高线 90%）
- 有效拒绝中 `query_graph`/`query_sensor` 的"该拒绝却调用" qwen 100%、边界清晰 → 维持办 §3.1.1 档线，不因 Schema 简化放宽。

## 四、判分口径建议（`judge_tools.py` 升版要点）

| # | 现口径 | 建议(v2) | 影响档位 |
|---|---|---|---|

## 五、预期收益与风险（代价标注）

| 项 | 说明 |
|---|---|
| **预期收益** | ① 参数校验 / 单工具档过苛误判消除；② 多工具档由"单响应硬限"转为"拆步可达成"，M0.2 有解；③ 写操作考点厘清，多轮档不再被幂等/格式叠加拖累 |

| **后续动作** | ① 按本清单升 Schema v2 + 改判分器 → `--selftest`；② 重测 20 用例（EXP-V1-006）；③ 按分档判据复核 M0.2 |
