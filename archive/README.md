## 为什么单独放

`reports/` 下原有 3 份与本项目的技术验证无关的个人材料（求职素材），且**全仓零引用**（孤儿文件）。它们与项目报告混放会导致两个问题：① 读 `reports/` 索引的人误以为是项目产物；② 项目交付打包时会连带无关内容。因此整目录移出，**内容一字未改**，只改路径与文件名（映射见 `docs/prj-spec-document-standard.md` §6.3）。
