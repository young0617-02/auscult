> **状态**：✅ 定稿（2026-10-22）｜ **适用**：Phase 6 停止条件 S2、交付材料、对外汇报、README/简历
> **动机**：同一指标曾**三套口径并存**（`0.91/5.6ms/0.9422` vs `1.0/159.4ms/1.0` vs `89.33%/98.67%`），
> 任何一处引用都可能被判定为"口径失真"。从本文件起，**对外只引用本表**；其他文档写指标时改为引用本文（`见 p6-metrics-canonical`）。

## 一、纪律

1. **一个指标只有一个对外值**。历史值可在复盘材料中出现，但必须写成"Phase 0 时点口径（已被取代）"。
2. **口径三要素缺一不可**：数值 + 测量方式（数据集/是否 rerank/是否打桩）+ 时间。
3. 凡"未达标"的指标**必须与达标指标并列展示**，不得只挑好的说（端到端 P95 9248.8 ms 就属此类）。
4. 本文件的任何修订都要在 §六 留一条变更记录，并同步 `plan/Phase 6` §7.2。

## 四、不得作为对外值的数字（黑名单）

| 数字 | 为什么不能对外 | 可用的场合 |
|---|---|---|
| `0.91` / `5.6 ms` / `0.9422` | Phase 0 旧基线（golden 50 题 + 10 万块压力档 + 同日多轮聚合），与当前产品形态不同 | 仅"Phase 0 历史"复盘，且必须标时点 |
| `84.0%`（GATE2）、`82.67%`（GATE-D 全量） | 已被 P1 参数指引取代的**旧评测**；GATE-D 的 87.3% 是"有效样本口径"，易与全量混淆 | 改进幅度对照（+11.4pp），须标注"改进前" |
| `1.0`（P5 十二项中的"工具调用首次成功率"） | 该行实为**检索执行口径**（12/12 题检索命中），与 LLM 工具调用不是同一件事 | `reports/p5-eval.md` 内部表格，须保留括号注释"检索执行口径" |
| `940 ms`（p5-perf u50 HTTP P95） | HTTP 端点聚合压测，不是检索 P95 | 性能报告内部，须标明"HTTP 端点" |

## 五、局限声明（引用上表任一时必须一起给）

1. 全部指标基于**模拟语料 + 本地/云端模型**，不代表生产级评测（`reports/p5-eval.md:5`）。
2. 语料规模为演示级（36 子块），Recall 类指标**天花板低**；扩语料后须重评。
3. 真实数据授权未取得（风险册 R15 显式接受）→ 结论**不得宣称现场可用**。
4. 工具成功率对**提示词版本敏感**，换 prompt 或换模型必须重测（R17/ISS-052 口径漂移风险的直接来源）。
