# V4b 压测 T8.4 判据核算（2026-09-24）

> 已定义口径：**B（宿主总占用）** = Windows 宿主 + WSL2/容器 + 宿主 Ollama。
> GPU：明示改走宿主原生 Ollama（U-03），门禁线「GPU 可直通」分支据此处置。

## 口径 B 峰值台账

| 核算项 | 实测 | 说明 |
|---|---|---|
| Windows 宿主空载基线（S0） | 19.65 GB | 固有桌面进程（IDE/浏览器/IM 等，非本项目） |
| 8 基础容器（etcd/minio/milvus/pg/redis/neo4j/mosquitto/tdengine） | 容器合计 ≈ **1.38 GB** | WSL2 内，docker stats 实测 |
| 宿主 Ollama（空闲进程） | ≈ 0.03 GB | 模型显存走 GPU，Host RAM 增量小 |
| 7B 模型 + 全容器后宿主总占用 | **26.38 GB / 31.80 GB** | 含宿主固有基线 |
| **本项目增量（宿主总 26.38 − 空载基线 19.65）** | **≈ 6.73 GB** | 容器 1.38 + Ollama/开销 + WSL2 膨胀 |

## 门禁判据核算

| 判据 | 目标 | 实测 | 判定 |
|---|---|---|---|
| 宿主总占用峰值（口径B绝对值） | ≤ 24 GB | **26.38 GB** | ⚠️ **超限**（超 2.38 GB / 9.9%） |
| 中间区间容限 | ≤ 26.4 GB（24×1.1） | 26.38 GB | ✅ **在容限内**（26.38 < 26.4） |
| GPU 可直通 | — | 改走宿主 Ollama（U-03 裁决） | ✅ 不依赖容器直通 |
| **综合判定** | — | — | **中间区间**（超限 ≤10% → 分组启动） |

> **核算结论**：按口径 B 绝对值，峰值 26.38 GB > 24 GB 门禁线，但超幅 9.9% ≤ 10% → 落入**中间区间**（对应报告 §八仲裁：**需分组启动 + 按需加载**）。
>
> ⚠️ **重要口径备注**：26.38 GB 含宿主固有桌面基线（19.65GB）。本项目实际增量 ≈ 6.73 GB 完全在预算内。判定「中间区间」是审慎口径：即便仅算本项目增量，容器+Ollama 也远低于 24GB；但门禁算式基数=物理内存×75% 要求按宿主总占用绝对值判，故取中间区间而非 Pass。
>
> ⚠️ 未纳入：应用后端/前端（无镜像）、reranker（无镜像）、BGE-M3+7B 同时常驻（临界，P0 仅用单模型）——均已按报告 §三.6 如实标注未测。
