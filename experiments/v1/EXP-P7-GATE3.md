### 1.1 本次唯一变更（相对 `EXP-P7-GATE2`）

| 项 | 变更前（GATE2） | 变更后（GATE3） |
|---|---|---|
| 被测 schema | `schemas/tools_v4.json`（5 工具，含写操作） | **`schemas/tools_v4_agent.json`（只读 4 工具；由 v4 派生、未改冻结件）** |
| `v1-019` | `forbidden_tool_calls=["generate_report"]`（禁调） | **真实多轮上下文考点**：`query_graph(start_node="PUMP-A-01", depth=2)`，设备号只能来自第 1 轮上下文 |
| 判分器 | 「禁调」语义被用例使用 | 「禁调」语义**保留但用例集不再使用**（写操作不在工具面 → 禁调即空转） |
| 其余 19 条 | — | 逐字未改（`test_redefinition_1020_revision_scope` 锁定） |

### 1.2 判据前置说明（不构成放宽）

- 移除写操作**不是**为了让模型少犯错：产品 Agent 的工具面本来就只有 4 个只读工具（ADR-007），
  让 V1 判据测一个产品里不存在的工具，是判据失效而非严格。
- 新增的 `v1-019` 考点比原用例**更难客观判定**（设备号不在输入文本里，必须继承上下文），
  且 `depth=2` 是历史失败过的参数（`v1-009` 曾错 depth）。

### 3.2 聚合（`scripts/aggregate_runs.py`，3 轮 × 25 = 75 样本）

| 档 | 通过/样本 | 聚合率 | 档线 | 裁决 |
|---|---|---|---|---|
| 单工具 | 15/18 | 83.3% | ≥85% | ⚠️ **中间区间（70–85%）** |
| 参数校验 | 12/12 | 100.0% | ≥85% | ✅ Pass |

### 3.3 失败样本归因（8/75，**全部为「参数值错」，零工具名错、零退化、零越界**）

| 用例 | 档 | 轮次 | 失败形态 |
|---|---|---|---|
| `v1-001` | 单工具 | R1、R2 | `window=15m` vs 期望 `1h` |
| `v1-004` | 单工具 | R3 | `direction=incoming` vs 期望 `both` |
| `v1-007` | 多工具 | R1 | `aggregation=raw` vs 期望 `max`（`raw` 是合法枚举但非本例正确值；多解仅 `trend`/`avg`） |
| `v1-008` | 多工具 | R1、R3 | `fault_keywords` 仅 `['振动']`，未覆盖 `轴承` |
| `v1-010` | 多工具 | R1、R2 | `time_range={'start':'24h'}` vs 期望 `1h` |

**结构性变化（相对 GATE / GATE2）**：
1. **多轮档 7/9 → 9/9**：`v1-019` 换成真实上下文考点后 3/3 通过；此前两轮的缺口全部来自写操作口径，与「多轮能力」无关。
2. **无任何越界调用**：写操作不在工具面，物理上不可能产生（GATE2 的 `调用禁调工具` 3/3 失败形态消失）。
3. 剩余缺口 8 个样本**全部集中在参数值/枚举选择**（window / direction / aggregation / fault_keywords / time_range），
   与 GATE/GATE2 的失败形态同源 —— 说明**这是模型在「参数默认值推断」上的稳定弱点**，不是工具面问题。

## 四、结论与处置

1. **本版分数的资格**：这是三版中**第一个「被测对象 = 产品工具面」的分数**，可对外表述为
   「云端 Qwen3.8-27B + prompt v4 + 产品只读 4 工具面：首成 89.33%，六档中四档 Pass、
   单工具/多工具为中间区间，无一档 No-Go」。**不得**与 GATE/GATE2 的分数直接比较（被测工具面不同）。
2. **仍未全绿 → 按纪律不切默认**（`deterministic` 不变）；但「No-Go」已降级为「中间区间」，
   处置从「要不要改判据」变成「**要不要补参数默认值指引**」。
3. **缺口性质改变**：8/8 失败均为参数值错，且 5 类参数在 GATE/GATE2 已反复出现（`v1-001/004/008/010`）。
   → **P1 候选**：在产品 Agent 提示词中补参数默认值/取值指引（**不动冻结区 `prompts/`**，
   改 `app/agent/prompt.py` 产品提示词），重跑本实验验证是否收敛。
4. **路径 D 的意义不变**：本版只证明「单轮工具选择 + 参数正确率」达到产品工具面口径；
   产品 Agent 的**多轮自主循环**（步数、证据归集、收口质量）仍须用 Agent 本体实测（见立项文档）。
5. **预算**：本轮 51 次；当日累计 195/340，未调锁。
