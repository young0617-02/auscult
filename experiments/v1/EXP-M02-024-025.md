## 五、结论

1. ✅ **H13 正面：`prompt v4` 是今日唯一整体非 No-Go 的臂** —— 整体由 `pv1` 的 **No-Go（拒止 67%）** 升为 **中间区间**；主集 `4a = 0`、无效拒绝档 **67% → 100%（Pass）**。

2. ✅ **H14 正面：拒止修复不依赖 `v5` 的写法** —— `prompt v4` 在**无泄漏迁移集**上 **15/15、`4a = 0`**，与 `v5` 等效（`pv1` 仅 12/15、`4a = 3`）。

3. ✅ **验证了上一轮对 `v1-019` 归因的更正** —— `pv5` 曾使 `v1-019` 由 3/3 掉到 0/3，而 **`v4` 含同款规则 6b 却保持 3/3** → **"6b 误伤写工具"确非充分原因**，原归因降级为候选假设是正确的处置（见 `EXP-M02-020-022.md` §3.2 更正块）。

4. ⚠️ **代价明确**：**单工具档 100%（Pass）→ 78%（中间区间）**；`v1-001` / `v1-004` / `v1-007` / `v1-010` 各有 1–4 次失败。

5. 🔁 **新发现：拒止与单工具在"提示词层面"是**可复现**的互斥，而非噪声** ——
   - **`v1-016`：`pv1` 0/3 → `pv4` 3/3 → `pv5` 3/3**（**两个独立提示词版本均修复**）
   - **`v1-001`：`pv1` 3/3 → `pv4` 0/3 → `pv5` 0/3**，且两臂的失败值**恒为** `window 期望 '1h'，实际 '15m'`（**两个独立版本上同向复现、且每次重复一致**）
   → **两版"拒止强化"提示词都修好同一处、打破同一处** → **提示词层面无法同时满足** → `EXP-M02-009` §下一步提出的**架构解耦（拒止前置门 R-1 本地化）**由此获得**独立复制**的支持，应升为**首选方向**。

6. 📌 **对 `EXP-M02-010`"`v1-001` 属噪声"判定的限定**：该判定在**同一 prompt 内**成立（跨运行正反均现）；但本批数据显示 **`v1-001` 的 `window` 在 `pv1` 与两版强化提示词之间存在稳定、同向的差异** → **不得**将其简单归为噪声，跨 prompt 版本比较时应按**效应**看待。

7. 📌 **对 `ISS-026`（"拒止行为对 prompt 文本高度敏感、效应不可迁移"）的修正**：应**收窄**为——
   - **拒止修复本身可迁移** ✅（迁移集 15/15，两条独立提示词版本均达成）；
   - **但其副作用同样可复现**（`v1-001` 在两条独立版本上均 0/3）→ **不是"随机/不可预测"，而是"稳定但方向不利"**。
   → `ISS-026` 原判读"不可迁移"**对拒止效果而言不成立**，对**副作用**则应改为"**稳定可复现**"。

8. ⚠️ **`M0.2` 仍为 No-Go**（无人全档 Pass；`pv4` 有两档落中间区间）。**本次未改动判据、用例与阈值**。
