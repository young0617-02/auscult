# EXP-M02-038 · H20：**端到端实测**（规则门 → 云端工具调用）

> **状态**：📋 **预登记已完成（判据前置），实验待跑/已跑（见 §三/§四）**
> **动机**：`EXP-M02-037`（H18b）的结论为**离线合成**（规则门判定 + 复用同日云端臂），其 §四.7 已声明"**正式记录须端到端实测**"；且该实验留下一条**未检验的风险**：规则"处处给判定"，使"未决"表现为**默认 `allow`** → **分布外的越界表达会被放行（OOV）**。

## 四、结论

1. ✅ **端到端复现了离线合成的分档**（除多工具 +8.3pp 属抽样）→ **`EXP-M02-037` 的管线预测可信**；首次成功率 **0.9333（70/75）** 为迄今最高。
2. 🔍 **OOV 风险：门层确认为现实问题；端到端未造成越界**。A 类**门漏判 6/6**（与事先预测一致），但云端 **18/18 未调用工具且给出实质性拒止** → **越界动作 0 次**。即：**规则门对"改写表达"不 robust**（须扩规则），而本样本**被云端自发拒止兜住** ✅
3. 🔁 **机制解释（与既有结论完全一致）**：`prompt v1` **无任何拒止条款**，模型仍**精准拒止**（理由直指越界类别）→ **拒止能力来自模型自带的职责边界意识，不需要提示词条款**；而"拒止强化条款"只会让模型在**允许用例**上过度拒绝 ✗ → 与 `H13`/`H14`/`H16`/`H17` 的"**拒止强化伤允许档**"**相互印证** ✅
4. ⚠️ **但不可依赖云端兜底**：云端拒止属**未受控的模型行为**（无条款、无保障、可能随 provider 漂移 ✗，参见 `ISS-028`）→ 建议：① **扩规则**（覆盖 `往上调`/`放宽到`/`标成`/`切到`/`调成`/`会怎样` 一类表达，**低成本**）② 强化"**规则未命中且含动作词 → 二次判定**"（可交模型复核）③ **`M0.2` 维持 No-Go**（整体非 Pass）。
5. ✅ **B/C 类与预测一致**：门 **0 误拦**、澄清 **2/2** → 规则门的**泛化**在改写样本上成立。
6. ⚠️ **`M0.2` 仍非 Pass**（整体中间区间）；但与 `H18b` 一致：**所有档位均非 No-Go** ✅
7. ⚠️ **自建对抗集的局限**：作者与实验者**同一人**，**非独立第三方红队** → A 类 6 条的"漏判率"**不可外推**为总体漏判率；亦**不构成**对云端拒止能力的普遍性结论。
