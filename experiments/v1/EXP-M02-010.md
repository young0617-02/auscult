# EXP-M02-010 · `EXP-M02-006` 逐字复现 + 5 轮可复现性评估（**关键负向发现**）

> **目的**：验证 `EXP-M02-006`（云端 + `tools_v4` + `prompt v1`，首次成功率 **0.90**）能否在同一配置下复现
> **日期**：2026-09-30 ｜ **判据**：`docs/p0-spec-gate-criteria.md` §3.1.1
> **原始数据**：`experiments/v1/raw/EXP-M02-010.jsonl`（20 条）+ `.meta.json`
> **状态**：⚠️ **未复现（0.90 → 0.80）**，并由此**推翻**本轮此前提出的"提示词族系统性互斥"结论

---

## 〇、结论先行（**最重要的一条**）

> **在 `repeat=1` 下，云端工具调用实验的档位判定不确定度达 ±17–33pp（每档仅 3–6 例，单例翻转即一档），因此 `EXP-M02-006` 的"4/5 档 Pass / 0.90"不可复现，本轮基于单次运行的多次配置对比结论亦须打折。**
> **→ `M0.2` 的最终判定必须基于 `repeat ≥ 3`。**

## 三、必须撤回 / 修正的结论

| # | 此前结论 | 修正后 |
|---|---|---|
| 1 | **"两个提示词族系统性互斥"**（`EXP-M02-009` §2.1、`p0-gate-review` 决策10、`CHANGELOG`） | ❌ **撤回**。该结论建立在"每配置仅 1 次运行"之上；**同配置复跑即推翻多例**（`v1-001`/`v1-006`/`v1-007`/`v1-009`/`v1-019` 在同一 prompt 下正反均出现）。**仅 `v1-016`（拒止）的 prompt 相关性稳健成立**；`v1-004` 为弱相关（样本仅 2 vs 3），`v1-010` 已证**与 prompt 无关** |
| 2 | **"`EXP-M02-006` = 4/5 档 Pass、0.90、唯一卡点拒止"** | ❌ **不可复现**：复跑为 **0.80**，单工具 100%→83%、多工具 75%→50% → **"唯一卡点"的表述不成立** |
| 3 | "`prompt v4` 整体升为中间区间"（决策10） | ⚠️ **须打折**：单次运行结果，处于噪声区间内 |

## 四、结论与下一步

1. **测量有效性不足已成为 `M0.2` 判定的首要障碍**：`repeat=1` + 每档 3–6 例 → 档位不确定度 **±17–33pp**，此前多轮"配置对比"的结论**均不可作为决策依据**。
2. **`H0（repeat≥3）` 由"前置校验"升级为「最高优先级、必做」**。
3. **建议的判定方案**：对候选配置（`prompt v1` 与 `prompt v2`/`v4`）各做 **20 用例 × repeat 3 = 60 次调用**，以 3 轮均值判定档位；**在 H0 完成前不得宣称任何配置的档位结论**。
4. **`prompt 维度`的判断需重估**：互斥结论撤回后，不能再说"该维度已触天花板"；但 `v4` 的拒止收益（稳健）仍值得保留。
