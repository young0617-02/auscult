# EXP-M02-011 / 012 · H0：双臂 × `repeat=3` 稳定档位判定（**决定性结论**）

> **目的**：`EXP-M02-010` 证实 `repeat=1` 档位不确定度 ±17–33pp → 本实验以 **`repeat=3`** 取得**可判定**的稳定档位

## 〇、结论先行

| 档 | 线 | **H0-A（`prompt v1`）** | **H0-B（`prompt v4`）** | 判定 |
|---|---|---|---|---|
| 单工具 | ≥85% | **18/18 = 100%** ✅ | **14/18 = 78%** ⚠️ | **两者互斥** |
| 参数校验 | ≥85% | 12/12 = 100% ✅ | 12/12 = 100% ✅ | **完全稳定** |

| **整体** | 最差档 | **中间区间** | **中间区间** | — |

**三条决定性结论**

1. **多工具档 = 50%（两个配置完全相同）→ 与 prompt 版本无关的硬阻塞**，且是**最硬瓶颈**。
   稳定失败用例为 **`v1-007` 与 `v1-010`（两臂均 0/3 全失败）** → 多工具档需 ≥3/4 才达 70%，**必须修好其中至少一条**。
2. **「拒止 ↔ 单工具」互斥在 `repeat=3` 下确认成立（非噪声）**：
   `prompt v1` → 单工具 **3/3、3/3**（`v1-004`/`v1-005`）而拒止 **1/3**（`v1-016`）；
   `prompt v4` → 拒止 **3/3** 而 `v1-004`/`v1-005` 降至 **1/3、1/3**。
   → **`EXP-M02-009` 的"互斥"判断在收窄到「拒止 vs 单工具」后成立**（此前基于 `repeat=1` 的宽泛表述已由 `EXP-M02-010` 撤回；本次以 `repeat=3` 重新确立）。
3. **`参数校验` 与 `多轮` 两档在两臂、三次重复下 100% 稳定** → 可作为既定能力。

### 1.1 稳定失败用例的原始证据

| 用例 | 臂 | `call_issues`（3/3 一致） |
|---|---|---|
| `v1-007` | 两臂 | **`aggregation` 期望 `max`，实际 `trend`** |
| `v1-010` | v1 | `aggregation` 期望 `avg` 实际 `trend` **+ 工具缺失：未调用 `search_knowledge`** |
| `v1-010` | v4 | **`time_range` 期望 `1h` 实际 `24h`** + `aggregation` 期望 `avg` 实际 `trend` + 未调用 `search_knowledge` |

> **关键观察**：**`v1-007` 与 `v1-010` 的失败均含 `aggregation` 语义选值（模型系统性给 `trend`，期望 `max`/`avg`）** —— 属**参数值语义**瓶颈，且**两臂完全一致**。
> 而 `tools_v4` 的 F2 修正**只补了 `sensor_ids` 描述，未补 `aggregation` 描述** → **存在与 F2 完全同类的"任务信息不足"缺口未补**。

## 二、结论

1. **`prompt` 维度已可确认触顶**：两个候选 prompt 均**无法同时满足 5 档**——`v1` 卡拒止 + 多工具；`v4` 卡单工具 + 多工具。
2. **多工具档（50%）是最硬的、与 prompt 无关的阻塞**，且失败根因**收敛到 `aggregation` 语义**（`v1-007`/`v1-010` 两臂 3/3 一致）。
3. **`H0` 达成其目的**：以 `repeat=3` 得到**可判定、可复现**的档位，替代了此前 `repeat=1` 的不可靠结论；并**收敛了待办**：从"5 档不明"收敛为 **单点问题（多工具档，2 条用例）** + 一处 prompt 侧取舍（拒止 vs 单工具）。
4. **`EXP-M02-006` 的"0.90 / 4 档 Pass"在 `repeat=3` 下不成立**：正确表述为 **单工具/参数校验/多轮 100%，无效拒绝 78%，多工具 50%**。
