## 〇、结论摘要（终版）

- **P5（缩描述 + 可选降级）为负结果**：v3 相比 v2 **未带来增益，且整体回退**。
- **M0.2 仍 No-Go**，双模型最差档均为**多工具 0%**（触发架构切分）。
- deepseek-r1:7b 明显劣化：参数校验 **87%(Pass) → 60%(No-Go)**、单工具 33% → 14%、多轮 67% → 58%；「应调用却拒绝」2 → 9。
- 唯一改善：qwen 无效拒绝 **75% → 100%（Pass）**、「应拒绝却调用」3 → 0。
- **解读**：描述精简移除了**承重的语义线索**（参数语义选择本就依赖 description），与 `EXP-V1-NORM` 归因（瓶颈在模型参数语义选择 + 多工具编排，非 Schema 结构）一致。

## 四、落地结论与建议

1. **M0.2 不放行**（与既判一致，根因仍为多工具 0% + 单工具低档）。
2. **P5 缩描述/可选降级已撤回（2026-09-30 决策）**：v3 描述精简移除了承重线索，负向影响大于正向。**活动 Schema 已回退 `tools_v2.json`**（`judge_tools.py` `SCHEMA_PATH` 已指回 v2，判分口径 D1–D5 不变）；`tools_v3.json` 标记 `RETIRED_NEGATIVE_RESULT` 保留为负结果快照；`docs/version-lock.md` §2.6 活动版改回 v2。
3. **多工具硬限是唯一真瓶颈**：双模型 0%，需走**架构切分**（交云端 / 拆单工具多轮），该路径依赖判分器 **D4 多工具拆步**（当前未实现）。
4. `tools_v3.json` 保留为**负结果实验快照**，不追改。
