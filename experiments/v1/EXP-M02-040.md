# EXP-M02-040 · H22：**同日多轮聚合口径**裁决 `M0.2`（Phase 0 收尾）

> **状态**：✅ **已实测**（预登记先行，2026-10-08）
> **授权**：用户于 **2026-10-08** 明确授权「**同日多轮聚合口径**」（判据口径修订）+ 3 轮执行；**沿用原档线、不放宽**
> **动机**：`EXP-M02-038`/`-039`（H20/H21，**均 10-07 同日**）显示 —— 同一份逐字配置、同一天两轮，卡点即在**单工具 ↔ 多工具**之间漂移（单工具 83.3%↔88.9%、多工具 83.3%↔66.7%）→ **`ISS-028`「单日点估计不足以裁决 `M0.2`」已被实证**。
> **成本**：云端 **153 次**（3 轮 × 主集 allow 17 × repeat 3）；10-08 预算 340/日，**无需调锁**

| **聚合口径** | `scripts/aggregate_runs.py`：把 3 轮 raw 的**逐样本**（每用例 **9 个样本**）合并；各档率 = 合并通过数 / 合并样本数 |
| **档线（**不放宽**）** | **一字不改**（单工具/参数校验/多轮 ≥85%、多工具 ≥70%、拒止/澄清 ≥90%） |
| **决策规则（**先声明**）** | ① 全档合并率 ≥ 各自档线 → 整体 **Pass** → **`M0.2` 达成 → 放行 `M0.6`**；② 任一档 < 档线 → **维持中间区间/No-Go → `M0.6` 仍不放行** |

| **诚实边界（**预先声明**）** | 多轮聚合**降低抽样误差**，但**不消除 provider 侧系统性偏移**（`ISS-028`）；结果**仍须标注不确定性** |

**防「移动球门」论证**（详见 §二）：不降档线、符合既有降噪原则、预登记 + 固定轮数 + 不挑选、依据 `ISS-028`（2026-10-05 已登记）而非事后构造。

## 五、结论

1. ✅ **`M0.2` 达成**：按**预登记的同日多轮聚合口径**，**全部六个档位均过闸** → 整体 **Pass**。
2. ✅ **`M0.6` 具备放行条件**（M0.1/M0.3/M0.4/M0.5 已达成 + M0.2 达成）→ 已同步 `docs/gate-criteria.md` §六 与 `reports/P0-summary.md` 决策34；**新口径写入 `docs/gate-criteria.md` §3.1.3**。
3. 🔴 **必须附带的限定与残余风险（不得略去）**：
   - ① **单轮口径仍不稳**：R1 单轮判**中间区间**（多工具 58.3%），R2/R3 判 Pass（83.3%）→ `M0.2` 的达成**依赖聚合口径**，**不改变**"云端单日点估计不稳定"这一事实（`ISS-028`）。
   - ② **多工具档余量小**：75.0% 仅高于 70% 线 **5.0pp**（27/36）→ **再漂移 2 个样本即可能跌破**；
   - ③ **聚合口径与单轮口径不可直接比较**，`-038`/`-039` 保留不改；
   - ④ **provider 不可 digest 化**（`ISS-028`）：本结论**依赖 provider 版本**，跨日/跨版本**不可直接复用**。
4. ✅ **门侧无异常**：拒止/澄清 100%（合并 72/72），门短路 72 条判定全对。
