### 1.1 与路径 C 的可比性边界

- **不可直接比大小**：C 是「单轮、prompt v4、无循环」；D 是「多轮、产品提示词、有循环」。两者分数差异 = 提示词 + 循环 + 步数上限的**复合效应**，不得归因为单一因素。
- **可比的是同集同档线下的失败形态**：C 的 8 个失败全为参数值错；若 D 在同样用例上出现新形态（收口 JSON 解析失败、空转、越权），即为**循环引入的新风险**，须单列。

### 3.4 三项必须声明的口径偏离（如实登记，不掩盖）

| # | 偏离 | 影响 | 处置 |
|---|---|---|---|
| **a** | **打桩未生效**：`main()` 漏调 `install_stubs()`，R1–R3 实际走**真实工具链路**（本地 Milvus / PG / TDengine 真实查询） | 4 次 `query_sensor` 报「缺少参数 sensor_ids 且无法从告警推断测点」（`v1-011` R1、`v1-001` R2、`v1-007` R3、`v1-018` R3），模型据此改写参数继续；分数因此**不等同**于预登记的打桩口径 | ✅ 已修（默认装桩 + `--no-stub` 显式开关）；`tests/test_agent_gate.py` 6 例锁死（含「默认必须装桩」的直接回归） |
| **b** | **`max_steps=2`**（产品默认 4） | 48/51 样本触发强制收口 → **产品 Agent 在 2 步内几乎从不自行收口**（该现象本身即为结论，见 §3.5-3） | `max_steps=4` 的完整循环须另择日补测（预算） |
| **c** | **预算超支**：实际 **150 次** LLM 调用（预估 108）→ 当日累计 **345/340**，超 5 次 | 超出当日锁 5 次（≈1.5%） | 如实登记；**当日停止一切云端调用**，不调锁 |

> 打桩未生效反而提供了一个副产品：这版分数测的是「产品 Agent + 真实工具」——比打桩更接近真实链路，但**受"用例无告警"这一结构性缺陷干扰**，不能直接当作产品的端到端结论。

### 3.5 结构性发现（D 的核心价值：暴露 C 结构上测不到的三处摩擦）

1. **收口契约 vs 用例形态错配**：`v1-014`（"4.5 mm/s 是哪个标准规定的？"）三轮都以**markdown 表格「回答」**收口，而非诊断 JSON → `json_parse_ok=False` 3/3。产品 Agent 的收口契约是「诊断结论 JSON」（因为产品入口永远是告警），而 V1 有一部分**问答型**用例 —— 判据与产品形态在**收口面**再次不匹配（与 `ISS-052` 同类，但发生在收口而非工具面）。
2. **工具测点依赖告警**：`query_sensor` 需要 `sensor_ids` 或从告警推断；D 的问答驱动 `alarm=None` → 结构性摩擦。产品形态下合理（诊断始于告警），但**判据集不提供告警**。
3. **循环不自行收口**：2 步内 94% 被强制收口 → 若产品用默认 4 步，真实诊断会走满 4 步，延迟/成本显著高于 C 的单轮估计 —— **与 U2「异步诊断」判决互相印证**。

## 四、结论与处置

1. **D 首版分数：62/75 = 82.67%，四档工具类中间区间、拒止/澄清 Pass、无一档 No-Go**。按纪律 **不切默认**（`deterministic` 不变）。
2. **与 C 不可比**（复合效应：产品提示词 + 多轮循环 + 步数上限 + 真实工具）；可比的是**失败形态**：13/13 仍是参数值错，**没有出现新的"能力型"失败**（工具名错 0、空转 0、越权 0）。
3. **两处结构性摩擦（收口契约、测点依赖告警）必须先修，D 的分数才有资格代表产品端到端质量**。否则 D 只是「把 C 的判据套在产品壳上」。
4. **下一步（建议顺序）**：
   - ① **harness 修**（半天）：打桩补 `sensor_ids`/告警前置（给用例注入最小 `AlarmEvent`，与产品入口一致）；收口允许「问答式答复」并**单列** `answer_mode` 指标（不进六档）；
   - ② **补 `max_steps=4`**（另择日，预算 ≈ 17×4.5×3 ≈ 230 次，需单独排日）；
   - ③ **P1 参数默认值指引**（`app/agent/prompt.py`，不动冻结区）→ 与 C 的 8 个失败样本共用一套修复；
   - ④ 修完后重跑本实验，才是「可裁决切默认」的那一版。
5. **预算**：见 §3.4-c（345/340，超 5 次；当日封盘）。
