## 一、结论

| 项 | `EXP-M02-007`（v2, max_tokens **1024**） | **`EXP-M02-008`（v2, max_tokens 2048）** |
|---|---|---|
| 首次成功率 | 0.8500 | **0.7500（↓）** |
| 参数 JSON 可解析率 | 0.9412 | 0.9412（**不变**） |
| **格式退化条数** | **1** | **1（不变）** |
| 失败归类 | `{参数值错:2, 格式退化:1}` | `{参数值错:4, 格式退化:1}` |
| think token 均值 | 878.2 | 723.2 |
| 分档 | 单工具 83% / 多工具 75% / 多轮 67% / 拒止 100% | **单工具 67% / 多工具 50% / 多轮 67% / 拒止 100%** |

**结论**：**提高 `max_tokens` 不修复 `v1-019` 的格式退化**（仍为 1 条），反而引入更多参数值错（2→4）→ **"截断型格式退化"假设不成立**。

## 二、机制修正

`v1-019` 的 `call_issues` 实为 **「工具缺失：未调用 `generate_report`」**（非输出被截断）→ 属**行为/意图类失败**，与 `max_tokens` 无关。**`EXP-M02-007` §3.1 基于 think token 上升提出的"截断"判读应予撤回。**
