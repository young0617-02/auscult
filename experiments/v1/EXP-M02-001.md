## 五、逐条明细与机制归因

| case_id | 类型 | 结果 | 失败原因 | 工具名 | 工具集 |
|---|---|---|---|---|---|
| v1-001 | 单工具 | ✗ | **格式退化** | ✗ | ✗ |
| v1-005 | 单工具 | ✗ | 参数值错 | ✓ | ✓ |
| v1-007 | 多工具 | ✗ | 参数值错 | ✓ | ✓ |
| v1-010 | 多工具 | ✗ | 参数值错 | ✓ | ✓ |
| v1-013 | 参数校验 | ✗ | 参数值错 | ✓ | ✓ |
| v1-016 | 无效拒绝 | ✗ | **该拒绝却调用** | ✗ | ✗ |
| v1-018 | 多轮 | ✗ | 参数值错 | ✓ | ✓ |
| v1-019 | 多轮 | ✗ | 参数值错 | ✓ | ✓ |

**归因**：
1. **编排不是瓶颈**：多工具 4/4 集合覆盖正确（`1b=1.00`），但用例级仅 50% → 云端"选对工具"没问题，**卡在参数值**（window/time_range 等语义）。
2. **参数值语义是跨模型共同瓶颈**：云端参数值正确率 **0.5882**，与 EXP-V1-005（0.5294）几乎一致；P6 本地拆步后失败亦 100% 收窄到参数值错（EXP-V1-009）→ **本地/云端同源**，非模型规模可解。
3. **无效拒绝**：4a=1、4b=1，qwen 云端拒止 67% < 90% 线（本地 qwen 单独测试曾 100%）。
4. **格式退化仍偶发**（1/20，v1-001）：云端结构化输出未 100% 收敛。

## 七、遗留与结论指向

1. **M0.2 处置链 ①②③④ 已全部执行**（约束解码 / few-shot / Schema 简化 / 混合形态），**整体仍 No-Go**——四步加固均未把首次成功率推过档线。
2. **判据可达性存疑**：云端 27B 亦仅 0.60（参数值 0.5882），提示 `85%/90%` 档线在当前**用例参数值口径**下"无模型可达"——与 `p0-report-v1-tool-call.md` §7.3 归因一致（判据定得过高 + 用例口径不严 + 7B 编排硬限三者叠加，其中前两者对云端同样成立）。
3. **指向**：下一步应优先**复审参数值判据/用例口径**（time_range/window/depth 的语义等价边界），而非继续更换或加大模型。
4. 单轮小步（repeat=1）样本量有限，分档百分比粒度为 25%（4 用例）～33%（3 用例），结论方向可信、精度有限。
